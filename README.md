# 🕯 Хвилина мовчання АКМЦ

Щоранку о 9:00 бот публікує в Telegram-каналі АКМЦ (а згодом і у Facebook) історію однієї людини з Донеччини чи Луганщини, яку вбила Росія. Історії бере з платформи пам'яті [«Меморіал»](https://memorial.ua).

## Як це працює

1. **≈6:15–7:15.** Бот оновлює список людей на memorial.ua, обирає людину й надсилає **чернетку тобі в особисті**.
2. **Якщо щось не так**, напиши боту «стоп», і сьогодні пост не вийде.
3. **О 9:00** пост виходить у канал **без звуку сповіщення**.

**Графік тижня**

| Пн | Вт | Ср | Чт | Пт | Сб | Нд |
|---|---|---|---|---|---|---|
| цивільні | військові | цивільні | військові | цивільні | військові | дитина |
| Донеччина | **Луганщина** | Донеччина | Донеччина | **Луганщина** | Донеччина | Донеччина |

- **Річниця загибелі** має пріоритет над графіком.
- Якщо потрібних людей не залишилось, бот бере найближчий варіант (іншу область, потім цивільних).
- Кожна людина публікується лише один раз. Список уже опублікованих лежить у `state/published.json`.

**Хто вважається «з Донеччини / Луганщини»**
- **Цивільні й діти:** місто народження в області, або в описі сказано, що людина звідти, або людина загинула на території області.
- **Військові:** лише місто народження чи «родом з…» в описі. Захисник з Полтави, який загинув під Бахмутом, сюди не потрапить.
- Людей **без фото** чи з дуже коротким текстом бот пропускає.

## Налаштування (один раз)

### 1. Створи окремого Telegram-бота
1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → дай назву, наприклад «Хвилина мовчання АКМЦ».
2. Збережи **токен**, який він видасть (`123456:ABC...`).
3. Знайди свого бота в Telegram і натисни **Start**. Без цього бот не зможе писати тобі.
4. Дізнайся свій **ID**: напиши [@userinfobot](https://t.me/userinfobot), він відповість числом.
5. Додай бота **адміністратором** у канал @acmc_ua з правом публікувати повідомлення.

> Бот має бути окремим, не «Мурчиком», бо він читає твої «стоп».

### 2. Створи репозиторій на GitHub
1. GitHub → **New repository** → назва `memorial-bot`. Можна зробити його **публічним**: тоді хвилини GitHub Actions безкоштовні без ліміту. Секретів у коді немає.
2. Завантаж усі файли з архіву: **Add file → Upload files**. Папка `.github` теж потрібна.

### 3. Додай секрети й змінні
**Settings → Secrets and variables → Actions**

Вкладка **Secrets** → *New repository secret*:
| Назва | Значення |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен від BotFather |
| `REVIEW_CHAT_ID` | твій ID від @userinfobot |

Вкладка **Variables** → *New repository variable*:
| Назва | Значення |
|---|---|
| `CHANNEL_ID` | `@acmc_ua` |
| `PUBLISH_TO_CHANNEL` | `false` (поки тестуємо) |

### 4. Перший тест
**Actions → Хвилина мовчання → Run workflow → mode: test → Run.**

Перший запуск триває **15–20 хвилин**, бо бот один раз переглядає всю базу «Меморіалу». Далі щодня лише нові записи, тож це хвилина-дві. У результаті тобі в Telegram прийде чернетка.

### 5. Запуск
- **Поки `PUBLISH_TO_CHANNEL = false`**, бот щодня надсилає чернетку о ~7:00, а о 9:00 «публікує» пост теж лише тобі. Так можна кілька днів подивитися, як це виглядає.
- **Після дозволу «Меморіалу»** зміни змінну на `true`. З наступного ранку пости йдуть у канал.

## Facebook (пізніше)
Додай змінну `FB_PAGE_ID` і секрет `FB_PAGE_TOKEN` (токен сторінки з правом `pages_manage_posts`). Бот публікуватиме фото з текстом. Посилання веде на «Меморіал Героїв» для військових і на «Меморіал: вбиті росією» для цивільних і дітей.

## Картка
«Меморіал» просить не публікувати в соцмережах сирі фото з сайту, а лише оформлені картки. Тому бот сам робить картку 1080×1080 у стилі АКМЦ (`card.py`):
- фото людини чорно-біле, плавно переходить у темно-синє тло;
- ім'я, професія (для військових — підрозділ), місто, роки життя;
- унизу знак «Меморіалу» (папка `marks`): **голуб** для цивільних і дітей, **жетон** для військових, і підпис «Хвилина мовчання / Платформа пам'яті «Меморіал»»;
- тонка рамка: жовта #FFCC33 для цивільних і дітей, світло-синя #3A5EB2 для військових;
- шрифт Montserrat (лежить у папці `fonts`, ліцензія OFL).

**Логотип АКМЦ** уже лежить у `logo.png` (білі лінії на прозорому тлі) і стоїть у правому верхньому куті картки.

У Telegram підпис до фото обмежений 1024 символами, тож довга історія йде окремим повідомленням одразу під карткою.

## Що можна змінити
- **Текст першого рядка й завершення:** `post.py`, рядки `OPENING` і `CLOSING`.
- **Посилання на сторінки «Меморіалу»** (коли вони надішлють свої): `post.py`, `MEMORIAL_TELEGRAM`, `MEMORIAL_FACEBOOK`.
- **Графік:** `bot.py`, `WEEKDAY_CATEGORY` і `LUHANSK_DAYS`.
