# «Хвилина мовчання» — підсумок рішень (3.11.2026)

> Історичний документ; частину пунктів уточнено 6.11 (див. `tekhnichna-dovidka.md`).

**Відбір людей.** Цивільні й діти: місто народження в області, «з Краматорська / з Донеччини» в описі або загибель на території області. Військові: лише місто народження чи «родом з…». Лише категорії «Військові», «Цивільні», «Діти». Без фото чи з дуже коротким текстом — пропуск. Кожна людина — один раз.

**Графік.** Пн, Ср, Пт — цивільні; Вт, Чт, Сб — військові; Нд — дитина. Вт і Пт — Луганщина. Річниця загибелі має пріоритет.

**Пост.** Перший рядок про хвилину мовчання; ім'я та вік, місто й дата, у військових — посада й підрозділ; текст «Меморіалу» без змін; «Вшануймо пам'ять хвилиною мовчання», посилання, хештеги #ХвилинаМовчання #Донеччина / #Луганщина #Місто. Без пафосу. У Telegram — без звуку.

**Умови «Меморіалу».** Письмовий дозвіл і активне посилання на сторінку «Меморіалу» в тій самій соцмережі; сирі фото не публікувати — лише оформлена картка.

**Відкриті питання (на 3.11).** Через місяць — статистика відписок у Telegram і відгуки.
